넥슨 API 키 연결

내 캐릭터와 장비를 불러오려면 넥슨이 무료로 발급하는 API 키가 필요해요. 처음 한 번만 하면 됩니다.

  1. 넥슨 Open API 사이트 ↗에 들어가 오른쪽 위 로그인을 누르세요. 넥슨 ID가 없으면 회원가입부터 하면 됩니다.
  2. 로그인한 뒤 내 애플리케이션 → 애플리케이션 등록을 누르세요.
  3. 게임은 메이플스토리, 애플리케이션 타입은 개발 단계를 고르고, 서비스명에는 아무 이름(예: 메피티)이나 적으세요.
  4. 이용 약관에 동의하고 등록을 누르면 API Key가 자동으로 발급돼요.
  5. 애플리케이션 목록에서 방금 만든 항목을 눌러 API Key(test_로 시작하는 긴 글자)를 복사한 뒤, 아래 칸에 붙여 넣으세요.

키는 이 컴퓨터의 보안 저장소(Mac 키체인, Windows 자격 증명 관리자)에만 보관돼요. Mac에서 '키체인 접근 허용' 창이 뜨면 허용을 누르세요.

경매장에서 노작값 찾기확인 전

메피티 안의 경매장 창에서 넥슨에 한 번 로그인해 두면, 노작값을 모를 때 경매장에서 같은 이름의 가장 싼 매물을 찾아 씁니다. 공식 Open API가 아니라 넥슨 웹 경매장을 쓰므로 약관상 위험이 있을 수 있습니다. 경매장 검색은 하루 100회까지이고, 크롬·휴대폰 등 다른 곳에서 경매장을 열면 메피티 쪽 로그인이 풀릴 수 있습니다.
